# Reworked Stealth Bombers

Modified stealth bomber vs. defence unit interactions. Added a new unit [SAM + Radar] that is more than double as expensive as the typical sam unit but is dedicated in interception of those pesky stealth bombers with a unique promotion [Radar] that acts like the fighter ability but even more dedicated damage against bombers. Also the stealth bombers are no longer 100% evasion but 90%, meaning that the new SAM unit can actually do damage. Effectively it means that two SAM units make it a no fly zone, at the cost of being very expensive units.

Not designed with Nuke missile interceptions in mind, if suggestions for balancing please feel free to leave a comment.

Also uses Gods & Kings ruleset because uses Tech Telecommunications as a basis for when you can start building them.
